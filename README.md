# Codeforces DSA Practice

This repository contains my Java solutions to the 150 problems assigned by my college as part of the DSA Bootcamp.

### About
- **Platform:** Codeforces
- **Language:** Java
- **Total Problems:** 150
- **Difficulty Level:** 800–1400

### Purpose

These problems were assigned by my college after I scored **28/30 in DSA**. The objective is to:

- Strengthen my Data Structures and Algorithms fundamentals.
- Improve logical thinking and problem-solving abilities.
- Develop analytical and independent thinking.
- Build confidence in solving competitive programming problems.

My goal is not just to solve problems, but to understand the logic and improve my problem-solving approach.
